through td_screenshot from throwaway ops in /project1/_research_probe (deleted afterwards). Not downloaded; no third-party author.
- urdu_noto_nastaliq_rtl.png : Text TOP, font "Noto Nastaliq Urdu", reading direction right-to-left, my own Urdu test string (a greeting plus a phonetic spelling I typed myself; NOT the client's calligraphy and not for show use, shaping test only).
- urdu_geeza_pro_rtl.png : same string, font "Geeza Pro".
- pop_particles.png : Point Generator POP (sphere) -> Particle POP -> Select POP inside a Geometry COMP -> Point Sprite MAT -> Render TOP (640x360).
- pop_instancing.png : Grid POP (points) instancing a Torus POP via Geometry COMP (Default Instance OP = grid, Translate XYZ = P(0..2)).
- glsl_rings.png : GLSL TOP generator with a time uniform.
