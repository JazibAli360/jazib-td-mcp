## 1. Summary

1. **Everything below can be built with ops that exist in 31550 on this Mac** (all names checked in the dump): Particle / Feedback / Noise /
   Neighbor / Math Mix / GLSL / Lookup Texture / Trail POPs, GLSL TOP (pixel and compute modes) with the common `npasses` parameter, Feedback
   TOP, Render TOP + Point Sprite MAT. **No simulation here has been run in this build**; only a minimal POP particle render is live-verified
   (T-15). The two loop ops (Particle POP and Feedback POP with a Null target) carry an **open macOS crash risk class** (section 2, F11).
2. **Best fit for PRISM (soft, glowing, organic light; no hard graphics; Liquid Spectrum was rejected): curl-noise particle flow, Gray-Scott
   reaction-diffusion, physarum/mycelium glow, flocking swarm, attractor dust.** Fluids rank lower only because of the D4 rejection, not because of cost.
3. **Safest to build in 8 days: reaction-diffusion and the 2D fluid** are pure pixel-shader feedback (no POPs, no compute, no atomics),
   with MIT reference code or open maths. **Highest payoff / highest risk: physarum** (needs a POP-agent + TOP-trail double loop that nobody
   shows on Mac).
4. **Hard Mac limits** (macOS doc): no float atomics, no double attributes, no hardware ray tracing, no Nvidia Flex/Flow, MAT line-width
   parameter does nothing. So: scatter by **additive blending in a Render TOP**, not by atomics; no ClothPOP (CUDA, NVIDIA only).
5. **Measured counts on this Mac exist only for the bare particle render** (E): 2 M sprites at 24 px hold 60 fps, 4 M give 38.6 fps,
   10 M at 40 px give 11.5 fps, all at **7488x2880**. 1080x1920 has 10.4x fewer pixels, so the fill share shrinks; the compute share
   (forces, neighbour search) is resolution-independent and **has no measurement**. External figures (1 M particles at 60 fps, 1 M physarum
   agents at 60 fps) come from other hardware.
6. **Audio rule learned from a Derivative thread:** in Math Mix / Math Combine POPs, an expression in a Scope parameter makes the shader
   **recompile every frame**; drive values through the `vec` uniform page instead (F10). GLSL TOP/POP uniforms (`vec0valuex`) are fine.
7. **Camera rule:** Optical Flow TOP does not run on macOS (`DIRECTIONS.md` 4b). Use frame differencing, person mask (Lookup Texture POP)
   or the td-port helper; webcam clip is the default input (CLAUDE.md).
8. **Licences:** MIT references exist for fluids (Pavel Dobryakov, touchFluid), Lenia and gpu-io. **GPL-3.0** for Sebastian Lague's slime
   code and David Braun's boids: do not copy, reimplement from the papers. Almost every TD tutorial is a YouTube video with **no licence
   stated**; none of that code is needed.
9. Flash limits: sims are continuous, the risks are audio-driven brightness jumps and **stripe-regime patterns** (reaction-diffusion mazes,
   cyclic-CA bands). Clamp audio with Lag/Limit and keep to spot/coral regimes.
10. Ranked top 10 and build plans: section 6. Recommended for 8 days left: **1, 2, 3 (as one family), then 4 or 5 if time**.

## 4. Per-technique details

### 4.1 Curl-noise flow-field particles (POPs)
- **Look.** Thousands of soft sprites riding smooth, swirling, non-clumping currents; with Trail POP they become long light threads. Maps to the "Particle Weather / Open-Sky Release" families (`C_pf26_fit.md` job 4).
- **Why curl.** The curl of a vector potential is divergence-free, so particles neither bunch nor thin out (Bridson, Houriham, Nordenstam, "Curl-noise for procedural fluid flow", SIGGRAPH 2007; [PDF](https://www.cs.ubc.ca/~rbridson/docs/bridson-siggraph2007-curlnoise.pdf) - the PDF could not be text-parsed here, so the paper's content is cited from the file name and from the maths identity, not read: **UNVERIFIED** as to the paper's details).
- **References.** Derivative lesson "Working with the Noise POP" ([page](https://learn.derivative.ca/courses/100-fundamentals/lessons/109-pops-working-with-points/topic/working-with-the-noise-pop/), says only that the Output page offers gradient and curl); elburz, "Wavy Particle Systems in TouchDesigner using POPs", 17 Nov 2025, Particle POP + Math Mix POP, YouTube video, no licence stated ([page](https://derivative.ca/community-post/tutorial/wavy-particle-systems-touchdesigner-using-pops/73315)); Interactive & Immersive HQ, POP audio-reactive article using Point Generator, Grid, Noise, Merge POPs ([page](https://interactiveimmersive.io/blog/touchdesigner-operators-tricks/using-pops-to-drive-audio-reactive-visuals/)); non-particle cheap alternative: a.melv, "feedback flowfield fake particle look", 2 Apr 2025 ([page](https://derivative.ca/community-post/tutorial/touchdesigner-beginner-tutorial-feedback-flowfield-fake-particle-look/71665)), and `B_visual_techniques.md` row 1.
- **Build (31550).** Chain (names from dump/doc; the loop with forces is **not yet run in this build**):
  `pointgeneratorPOP` (rectangle/box slab, `createpointprim` on) -> `particlePOP` (`targetpop` = the closing Null, `maxparticles` N, `birthrate`, `life`, `lifevariance`, `damping`) -> `noisePOP` (simplex4d, **`curl3d` on -> `NoiseCurl`**, or `curl2d` -> `NoiseCurl2` for pure screen-plane flow with an ortho camera; Translate 4D = a wrapped time) -> `mathmixPOP` (`PartForce = NoiseCurl * k - PartVel * drag`, k and drag on the `vec` uniform page, **not** in Scope, F12) -> optional `forceradialPOP` (wind / vortex; remember `globforcemult` defaults to 0) -> `randomPOP` / `lookupattributePOP` + `curvePOP` (age -> alpha, size, colour ramp plum -> orchid -> pink -> gold) -> `nullPOP`. Render as in T-15: Select POP inside a Geometry COMP, Point Sprite MAT with additive `blending`, Camera COMP, Render TOP (`bgcolora` 0), then Bloom TOP. Trails: `trailPOP` after the Null (`attrmatch` on `PartId`) + Line MAT (**line width on macOS unverified**, F13), or fake trails with a Feedback TOP.
- **Compute-shader alternative.** Palette `particlesGpu.tox` (F21) is a texture-based compute particle system that avoids POP loops entirely; read its shader with `toeexpand` for ideas; whether it runs on Metal is **UNVERIFIED**. A custom GLSL POP can also integrate and sample the flow itself (F6).
- **Counts.** See section 5. F14 shows 2 M bare sprites at 60 fps at 7488x2880; with a Noise POP + Math Mix force pass in the loop there is **no measurement**. Start at 250 k, double until the frame time hits the budget (30 Hz: ~30 ms for the whole network, shared with Arena).
- **Audio.** Audio Spectrum CHOP -> Analyze/Envelope -> Lag CHOP -> `vec` uniform of the Math Mix POP: bass -> `k` (flow strength), mids -> noise Translate-4D speed, highs -> `PointScale` sparkle, beat -> short `birthrate` burst. Clamp with Limit CHOP so no >3 Hz full-field brightness jumps (F20).
- **Camera.** `lookuptexturePOP` (top = person mask or webcam clip frame) -> `Weight` -> multiplies the force or emission near people; frame-difference TOP sampled in a `glslPOP` (`sampler0top`) -> local push. Optical Flow TOP is not available (F17).
- **Licence.** Nothing copied: tutorials are videos with no licence; the build above uses documented parameters only.
- **Risks.** F11 (loop crash class; first test in a scratch COMP with a restart plan, one TD at a time); Particle POP 31550 lacks Jitter Birth (emission from points spawns on the point, `ops/POP.md` section 9), so emit from a Point Generator volume.

### 4.2 Reaction-diffusion (Gray-Scott)
- **Look.** Self-organising spots, coral, worm and maze patterns that grow and split continuously; at a distance reads as organic marbling.
- **References.** Karl Sims, "Reaction-Diffusion Tutorial" ([page](https://www.karlsims.com/rd.html)): 3x3 Laplacian weights centre -1, edge neighbours 0.2, diagonals 0.05; typical DA 1.0, DB 0.5, f 0.055, k 0.062, dt 1.0; "mitosis" f 0.0367 k 0.0649; "coral growth" f 0.0545 k 0.062; start A = 1, B = 0 with a small seeded patch of B = 1; kill range 0.045-0.07, feed 0.01-0.1. TD videos (no licence stated, no project files listed): Jack DiLaura via elburz, "Reaction-Diffusion Feedback Effects", 12 May 2022 ([page](https://derivative.ca/community-post/tutorial/reaction-diffusion-feedback-effects-touchdesigner-tutorial/66191), a short feedback loop, not a true Gray-Scott solver per the page text); Pao Olea, "Reaction Diffusion - TouchDesigner Tutorial [19]", 8 Apr 2025, two parts, adds audio reactivity ([page](https://derivative.ca/community-post/tutorial/reaction-diffusion-touchdesigner-tutorial-19/71701)); Dylan Roscover's paid "TOP Mastery" has an RD module ([course](https://pro.interactiveimmersive.io/courses/top-mastery-in-touchdesigner/)). A forum thread on converting RD shaders notes that setting the GLSL TOP Input Extend Mode UV to Repeat avoids edge artefacts ([thread](https://forum.derivative.ca/t/convertion-of-shaders-based-on-reaction-diffusion/129347), as reported by search summary: **UNVERIFIED** in detail).
- **Build (31550).** `Constant/Noise/Circle TOP` seed -> `Composite` (seed only on reset or injection) -> `Feedback TOP` (`top` = the Null at the loop end, as in `A_td_2025_howto.md` 6.1) -> `GLSL TOP` (pixel mode, `format` rgba32float or rgba16float: **which survives RD at slow rates is unverified**; A in R, B in G; 9 `texelFetch`/`texture` taps for the Laplacian; `vec` uniforms for f, k, DA, DB, dt; `inputextenduv` repeat) with **`npasses` 4-12** = substeps per frame (F10) -> `Null`. Display: second GLSL TOP / Lookup TOP maps B (and its gradient for an emboss light, as Sims describes) to the brand ramp. Sim at 540x960 and upscale, or native 1080x1920: both cheap vs 7488x2880; **no figure measured for this shader**, so run the E method (frame pump, count cooks) before choosing.
- **Audio / camera.** Nudge f and k by a few percent inside the pattern-stable window (Sims' f-k map) via Lag CHOP -> `vec`; bass can also inject a seed blob (Circle TOP in the Composite). Person mask -> seeds along the silhouette; a motion mask erases (B = 0) to open space.
- **Licence.** Sims' page is an explanation of maths; write the shader yourself. Tutorials: no licence stated.
- **Risks / brand.** Maze regime = parallel stripes at LED distance can trip the **>5 stripe-pair rule** (F20): stay in spot/coral, keep contrast low, tint inside plum-orchid-gold. Stalls: RD can freeze or saturate over hours; add periodic gentle re-seeding ("breathing") and a long-run soak test. Not loop-safe (feedback), fine for live.

### 4.3 Physarum / slime mould (mycelium glow)
- **Built (26 Oct, T-112): `GN_physarum`** = option B variant: compute agents + trail, deposit by a Render TOP of 1-px points with additive blend (exact, no atomics); `docs/builds/physarum.md`.
- **Look.** Millions of agents lay and follow a trail; the trail map blurs and decays, producing glowing branching veins that reorganise slowly. Very strong "alive" signature, soft light after a blur + bloom.
- **References and artists.** Sage Jenson (mxsage), physarum page ([page](https://cargocollective.com/sagejenson/physarum)): Jones-style model, agents with a position, heading and **three sensors (front-left, front, front-right)**; sense -> rotate -> move -> **deposit** into a 2D trail map -> 3x3 mean blur -> multiplicative decay; parameters: sensor distance, sensor size, sensor angle, step size, rotation angle, deposition amount, deposit size, diffuse size, decay factor; "most examples use 5 to 10 million particles ... real time on a GTX 1070"; C++/GLSL in openFrameworks. Jeff Jones 2010 paper ([UWE repository](https://uwe-repository.worktribe.com/output/980579), linked by the gpu-io page, not read). Nervous System residency write-up, 24 Aug 2022 ([post](https://n-e-r-v-o-u-s.com/blog/?p=9137), 3D physarum sculptures, not real-time). Entagma post on Jenson's work ([post](https://entagma.com/physarum-slime-mold/)). Amanda Ghassaei, gpu-io physarum, **all steps in WebGL fragment shaders** ([demo](https://apps.amandaghassaei.com/gpu-io/examples/physarum/), [library MIT](https://github.com/amandaghassaei/gpu-io); whether the example folder carries the same licence not checked). Sebastian Lague, Unity slime ([repo](https://github.com/SebLague/Slime-Simulation), **GPL-3.0**: do not copy). In TD: ciphrd, "Physarum transport network clean TOX", 21 Jul 2021 ([asset](https://derivative.ca/community-post/asset/physarum-transport-network-clean-tox/65070): parameters agent count, step, sensor angle/offset, rotation, diffusion, evaporation; 1,048,576 agents 60 fps on a GTX 2060; agents rendered by instancing, which limits the count; licence not stated; Mac not stated; not downloaded); reliqs, `audio_reactive_td_2025` repo with a `physarum` folder using GLSL TOPs, multi-pass, with audio mapping ([repo](https://github.com/reliqs/audio_reactive_td_2025), **no licence stated**: treat as all rights reserved; not downloaded); a Derivative forum "Physarum Transport Network in GLSL" thread (compute shader .toe, a reply said it did not work in 2021; [thread](https://forum.derivative.ca/t/physarum-transport-network-in-glsl/9962), via summary only). Not usable on Mac: LouieHext's openFrameworks compute shader needs OpenGL 4.3 ([repo](https://github.com/LouieHext/PhysarumComputeShader), via summary).
- **Build options for 31550.**
  - **A. Hybrid (recommended prototype).** Agents are POP points with a custom `Heading` attribute (declare it in the Particle/Feedback POP or GLSL POP `attr` blocks, dump). Loop: `pointgeneratorPOP` (N points in a rectangle) -> `feedbackPOP` (constant count, no births) -> **`glslPOP`** (compute; `sampler0top` = trail TOP; for each point read the trail at three sensor positions from `P` and `Heading`, turn, step, write `P`, `Heading`; `initoutputattrs` off if every output is written, F6) -> `nullPOP` = `targetpop`. **Deposit by rendering, not by atomics:** Select POP + Point Sprite MAT (1-2 px, additive blend) -> Camera (ortho, aligned to the trail TOP UV) -> Render TOP at trail resolution -> `Composite` add onto the previous trail from a `Feedback TOP` -> `Blur TOP` (3x3-ish) -> `Level TOP` (multiply = decay) -> `Null TOP` -> back into `sampler0top`. One-frame latency in each loop is fine for this model. Float atomics are unsupported on macOS (F13), hardware blending is the safe scatter. **Neither loop nor the TOP<->POP round trip has been run in 31550**; agent counts and Render-TOP cost for this pattern are **unmeasured**.
  - **B. Pure compute TOP.** Agent state in rgba32float textures, deposit by `TDImageStoreOutput` scatter in a GLSL TOP compute pass (`outputaccess` read-write exists in the dump). Without atomics, concurrent writes to one texel race (lossy deposit); whether integer atomics work through MoltenVK is **UNVERIFIED**. Use only if A fails.
  - **C. Look-alike without agents.** Feedback + flow-field displacement + blur/decay (the `B_visual_techniques.md` row 1 family; a.melv's tutorial above). Cheap, no POPs, and the right fallback if the show window closes.
- **Counts.** Cited: 1.05 M agents 60 fps on a GTX 2060 (2021, instancing); 5-10 M on a GTX 1070 (native). On this Mac: bare sprite render 2-4 M at 60/38.6 fps (F14), agent shader cost unmeasured. Start at 250 k agents.
- **Audio / camera.** Bass -> deposit amount and step size; mids -> sensor angle (changes network density); highs -> decay. Person mask composited into the trail as **food** (attracts) and motion as a repeller; webcam clip as the default feed.
- **Brand.** Colour comes from a Lookup of the blurred trail value (plum -> orchid -> pink -> gold). Keep thin and soft; neon-line density reads as "laser/net" which was denied (F19).
- **Licence.** Reimplement from Jones/Jenson's description; do not copy GPL code or unlicensed .tox.

### 4.4 Flocking / boids
- **Look.** A murmuration of small glowing sparks that stretches, splits and re-forms; reacts well to a beat (tighten/scatter).
- **References.** Dean Cheesman, "3D Flocking with POPs", 16 Oct 2025 ([page](https://derivative.ca/community-post/tutorial/3d-flocking-pops/73049); video [youtube](https://youtu.be/7_y2he5-_Q4); **project files on Patreon**, no licence stated; ops not listed on the page) and "Flocking Effect with TouchDesigner", 24 Jul 2024 (attract, repel, follow; [page](https://derivative.ca/community-post/tutorial/flocking-effect-touchdesigner/69859)); David Braun, "Boids / Flocking / Compute Shader for binning particles", 20 Sep 2021 ([page](https://derivative.ca/community-post/tutorial/boids-flocking-compute-shader-binning-particles/65246); repo [TouchDesigner_Shared](https://github.com/DBraun/TouchDesigner_Shared), **GPL-3.0**; its `Starters/boids` README credits Seb Lague's Unity boids and Chris Oat's "Efficient Spatial Binning on the GPU"). Neighbor POP docs (F4) describe exactly the needed outputs.
- **Build (31550).** `pointgeneratorPOP` (N points in a volume; initial `Vel` attribute via `randomPOP` direction) -> `feedbackPOP` (`targetpop` = Null) -> `neighborPOP` (by distance; `maxdistance` = perception radius; output = **Average** of `P` and `Vel`, `maxnebrsavg` capped; a second Neighbor POP in **Inverse Distance Weighted** mode for separation; `numhashbuckets` ~ N; leave distribution on the fast Default) -> `mathmixPOP` (cohesion `avgP - P`; alignment `avgVel - Vel`; separation `P - idwP`; sum weighted by `vec` uniforms; clamp speed; soft bounds via `fieldPOP` or `limitPOP`; integrate `P += Vel * dt`) -> `nullPOP`. Orient sprites or short Line MAT strokes along `Vel`. The second input semantics of Neighbor POP (2 inputs in the dump) are **UNVERIFIED**; read the local `neighborPOP` snippet (3 examples) before wiring.
- **Counts.** No figure for Neighbor POP anywhere found. The naive neighbour problem is quadratic in general GPU literature, Neighbor POP uses spatial hashing (hash buckets in the docs), so start at 20 k and measure 2x steps.
- **Audio / camera.** Kick -> separation up for 2-3 frames (burst) then back; spectrum centroid -> alignment; a person-mask centroid (`analyzePOP` on masked points, or Blob Track) as a predator/attractor.
- **Licence.** Reimplement the three rules (they are the textbook algorithm); do not take the GPL repo or the Patreon files.
- **Risks.** F11 loop class; Neighbor POP inside a Feedback POP loop not demonstrated by any source; look can drift to "tech swarm" - keep sprite soft and slow.

### 4.5 Strange attractors
- **Look.** Dense luminous filaments / dust clouds tracing Lorenz, Thomas, Aizawa, Halvorsen (organic shells and ribbons); rotates slowly.
- **References.** ETCH-01 (Amir Habibi), "TouchDesigner Tutorial 06 - Strange attractors (POPs)", 16 Aug 2025 ([page](https://derivative.ca/community-post/tutorial/touchdesigner-tutorial-06-strange-attractors-pops/72620), video [youtube](https://youtu.be/0cDQ79BrXzo), math tools + a bit of Proximity POP; no licence stated); equations and parameters for 12 systems at Juan Carlos Ponce Campuzano ([page](https://www.dynamicmath.xyz/strange-attractors/), 2018; e.g. Lorenz sigma 10, rho 28, beta 8/3; Thomas b 0.208186; Aizawa a .95 b .7 c .6 d 3.5 e .25 f .1; Halvorsen a 1.89; the page links a licence file I could not read, the equations themselves are the classical published systems); Attraktors Designer v0.7 (JiveFaury, 2022; TD 2021, Windows+macOS, Patreon, licence not stated; [asset](https://derivative.ca/community-post/asset/attraktors-designer-v07/66142)) is prior art only (a standalone app on a 1280-capped build). Function Store toolkit ([repo](https://github.com/function-store/FunctionStore_tools), MIT) has no attractor content.
- **Build (31550).** `pointgeneratorPOP` (N points in a small ball near the attractor) -> `feedbackPOP` -> **`glslPOP`** with `npasses` = substeps (F7: pass n+1 reads pass n; `TDPassIndex()`): compute `d = f(P)` in 6-10 lines per system, `P += d * dt`; attractor parameters from the `vec` uniform page. A Math Mix POP chain can do polynomial systems (Lorenz, Rossler) with `comb` blocks but sine/cubic terms get long; GLSL POP is clearer. -> `nullPOP`. Colour by speed: `mathmixPOP` length of `d` -> `lookupattributePOP` ramp. Render as additive sprites + Bloom; slow orbiting Camera COMP. Euler integration error is irrelevant visually; blow-up is not: add `limitPOP` on `P` and re-seed points that leave a radius (Delete POP / re-init pulse).
- **Counts.** No measurement. The GLSL POP does no neighbour work, so cost is closer to the bare particle render of F14 plus a small shader. Start at 200 k.
- **Audio / camera.** Slowly modulate one parameter (clamped, Lag 1-2 s; chaotic systems change shape abruptly with some parameters), `dt` with energy; webcam only as a colour source (`lookuptexturePOP`).
- **Licence.** Equations are public maths; write your own shader.
- **Brand.** Keep as soft dust, not thin neon lines (Proximity POP links read as lasers/nets, denied family).

### 4.6 Cellular automata and Lenia
- **Look.** Lenia: smooth, glowing "organisms" that glide and deform (Bert Chan's catalogue lists over 400 species in 18 families); cyclic CA: self-organised spiral waves; Game of Life: blocky lattice (too technical for PRISM).
- **References.** Lenia: Bert Wang-Chak Chan, "Lenia - Biology of Artificial Life", arXiv 1812.05433, Complex Systems 28(3) 2019 ([abs](https://arxiv.org/abs/1812.05433)); reference code **MIT** ([repo](https://github.com/Chakazul/Lenia), JS / Python-GPU / Matlab). Cyclic CA: David Griffeath; rule = a cell advances to the next state when enough neighbours already hold it ([Wikipedia](https://en.wikipedia.org/wiki/Cyclic_cellular_automaton)); low threshold with a large neighbourhood still spirals, high threshold settles into colour blocks, intermediate = "turbulence". **No TD tutorial for Lenia or Game of Life was found** (the one search that covered it returned only generic feedback material; second search blocked).
- **Build (31550).** GLSL TOP (pixel) + Feedback TOP as in 4.2. Lenia needs a large ring kernel (tap count grows with the square of the kernel radius R): at 1080x1920 that is heavy, so simulate at low resolution (e.g. 270x480) with `inputfiltertype` linear and upscale with a smooth Resize + Bloom; or test the Convolve TOP for the kernel step (**UNVERIFIED** that it keeps float precision and speed at large kernels). Cyclic CA needs only 8 neighbour taps: very cheap.
- **Audio / camera.** Lenia: wobble growth-function mean/width by a few percent; seed new blobs on beats; person mask as seeds. Cyclic CA: threshold/number of states from a slow LFO.
- **Risks.** Over hours a CA can die or freeze: needs auto-reseed. Cyclic CA spirals have strong repeating bands: check F20. Lenia look is closest to "bioluminescent organic light"; being unfamiliar, it needs the user's eye before a plan.
- **Licence.** Lenia MIT; the TD port would be written fresh.

### 4.7 Compute-shader particle fields (cymatic / Chladni-style)
- **Look.** Hundreds of thousands of grains settle onto standing-wave nodal figures and re-form when the pitch changes - sound made visible; soft sand.
- **Evidence.** Only one weak source: a re-uploaded video ("GLSL Cymatics System", Point Generator POP with 500,000 points, a GLSL POP displacing them, a feedback loop reset by an LFO, Noise POP closing it; [rutube](https://rutube.ru/video/0a180d67904606fcec93c45b9cd95a50/), original author and build **unknown**). The Chladni nodal-line equation (cos(n pi x) cos(m pi y) - cos(m pi x) cos(n pi y) = 0) is from memory: **UNVERIFIED**. Jack DiLaura's paid capstone "GLSL Particle Simulation in TouchDesigner" (GLSL TOP compute + feedback + curl, hundreds of thousands of particles, $147; [course](https://pro.interactiveimmersive.io/courses/glsl-particle-simulation-in-touchdesigner-capstone/)) is the TOP-compute counterpart; platform not stated.
- **Build (31550).** `pointgeneratorPOP` (rectangle, 500 k) -> `feedbackPOP` -> `glslPOP`: `f(P; n, m)`, step `P -= k * grad f + jitter` (jitter from `TDSimplexNoise()`), n/m from the `vec` uniforms -> `nullPOP`. Audio: `audiospectrumCHOP` peak bin -> quantised (n, m) with a Lag/hold so figures change at most every ~1 s (flash-safe, and the sand needs time to settle).
- **Counts.** 500 k is the figure in the one video; measure on this Mac. **Licence:** nothing to copy.

### 4.8 2D stable fluids (Navier-Stokes) and "fluid-driven particles"
- **Look.** Ink / smoke / light haze swirling with audio or motion impulses. Brand risk: "Liquid Spectrum" was rejected (F19). Safer use is invisible: the velocity field pushes particles (4.1) or advects a single-hue haze.
- **Algorithm (verified from two primary sources).** Per step: curl -> vorticity confinement -> divergence -> clear pressure -> **pressure Jacobi x N** -> gradient subtract -> advect velocity -> advect dye, with splats for forces. In Pavel Dobryakov's reference (read from `script.js`): `SIM_RESOLUTION` 128, `DYE_RESOLUTION` 1024, **`PRESSURE_ITERATIONS` 20**, `CURL` 30, `VELOCITY_DISSIPATION` 0.2 ([repo](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation), **MIT**, 16.7k stars; credits NVIDIA GPU Gems 38). GPU Gems ch. 38 ([page](https://developer.nvidia.com/gpugems/gpugems/part-vi-beyond-triangles/chapter-38-fast-fluid-dynamics-simulation-gpu), (c) NVIDIA, algorithm only) recommends 40-80 pressure iterations ("below 20 error becomes noticeable"), 20-50 for viscous diffusion (skippable for smoke). **Velocity on a coarse grid, dye on a fine grid** is the key cost saving.
- **TD references.** kamindustries, [touchFluid](https://github.com/kamindustries/touchFluid): "lightweight 2d Semi-Lagrangian fluid solver", vorticity confinement, temperature, buoyancy, obstacles, `.tox` + `.toe` + shader files in `include/`, **MIT**, from an MA thesis (UCSB), TD version not stated, originally CUDA (fork touchFluidCUDA) - 31550 compatibility **UNVERIFIED**. Aurelian Ionus (paketa12), "Fluid Simulation in TOPs", 6 Mar 2025: translation of Bruno Imbrizi's fluid using **native TOPs only** (tag noGLSL), optical flow from the palette component, `FluidSim_inTops_01C_0.toe` 18 KB, no licence stated ([asset](https://derivative.ca/community-post/asset/fluid-simulation-tops/71458)). Jack DiLaura via elburz, "Generative Liquid Paintings", 27 Nov 2023, a Shadertoy CFD shader adapted ([page](https://derivative.ca/community-post/tutorial/generative-liquid-paintings-touchdesigner/68643)). A TD Summit 2018 talk on a from-scratch Navier-Stokes advection with files under `ancillarymagnet/touchfluids` was mentioned in a search summary, the page could not be re-found: **UNVERIFIED**.
- **Build (31550).** All GLSL TOP (pixel) + Feedback TOP: velocity RG (rg16float or rg32float - **unverified which is stable**) at sim res; dye RGBA at 1080x1920. Nodes: curl, vorticity, divergence, **pressure `GLSL TOP` with `npasses` = 20** (input 0 = pressure from the Feedback TOP, input 1 = divergence; F10 says later inputs stay constant per pass), gradient subtract, two advection TOPs, splat Composite. Boundaries: `inputextenduv` hold/mirror. Output to POPs: sample the velocity TOP in a `glslPOP` (`sampler0top`) so the particles of 4.1 ride the fluid.
- **Counts / cost.** Nothing measured here. Structural cost: ~8 GLSL TOPs + 20 pressure passes at velocity resolution (small) + 2 advections at dye resolution.
- **Audio / camera.** Bass -> radial splat from a fixed emitter ring; spectrum -> splat colour index; frame difference (webcam clip) -> splat velocity (no Optical Flow TOP on Mac, F17).
- **3D fluids / SPH.** Nvidia Flex/Flow unavailable on macOS (F13); no TD POP-based SPH example found (the search returned none); a 3D grid solver in GLSL TOP 3D-texture outputs is theoretically possible, cost and pass count make it unrealistic by 24 Oct. **Not recommended.**

### 4.9 Cloth / soft body

- **What cannot be used.** ClothPOP (Unveil_studio, Jul 2026) runs "only on NVIDIA GPUs, using CUDA", free version capped at 5,000 points, **not for commercial use** ([asset](https://derivative.ca/community-post/asset/clothpop/75017)); ClothPOP PRO (Aug 2026, XPBD, CUDA, 10 EUR, one seat / one PC / one year, online activation; [asset](https://derivative.ca/community-post/asset/clothpop-pro/75143)). Treat as a concept, not a base.
- **Build (31550, my design, UNVERIFIED).** `gridPOP` (`surftype` quads, e.g. 200x300 = 60 k points, `dimension` set) -> `feedbackPOP` (carry `P` and `Pold`) -> `glslPOP`: Verlet `Pn = 2P - Pold + a dt^2`; structural/shear/bend neighbours via `TDDimCoords(i)` / `TDDimPointIndex(coords)` (F6, documented for grid-like data); constraints relaxed Jacobi-style with `npasses` (F7: inputs update between passes); sphere/plane collisions in the same shader; pinned row via a `Pinned` attribute. Render: Geometry COMP with Phong/PBR MAT; `normalPOP` must pick a technique other than Atomic Float (F13).
- **Why rank low.** Silk/curtain textures are Nano Banana strengths (`C_pf26_fit.md`), it is the highest custom-shader work, and constraint stability is untested here.

### 4.10 DLA / growth
- **Look.** Frost, coral or lightning-like branching clusters that grow slowly outward from seeds; a natural fit for 15-30 minute changeovers if it can regrow.

Saturates after a while: needs a fade-and-regrow cycle.
