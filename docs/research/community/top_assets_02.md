## Deep notes: top 15 by views in this slice
(price/licence/build/Mac as stated on the page or in the cloned repo; "audit" = what `toeexpand` + grep showed.)
1. **TD Scripts v1.4 and v1.3 (69030 4,417 / 68036 1,485, Artechs)** Blender add-on that writes TD python for meshes (multi-material beta), cameras
   (both directions by 1.4) and Principled-shader -> PBR MAT; a helper tox with a single `get` pulse runs the script. Patreon-only files (not fetched),
   Feb 2024. Same author: BPM Sequencer, MIDI/audio sync, TD Scripts. Blender-to-TD bridge pattern worth copying.
2. **Fluid Simulation in TOPs (71458, paketa12, 3,738)** Bruno Imbrizi's fluid solver rebuilt with TOPs only ("noGLSL"): 837 ops,
   mostly Reorder (228), Transform (144), Select, Math, Composite in feedback; optical flow from the Palette. Free 18 KB .toe, saved 2023.12000
   Windows, no licence. Audit clean (movie-out file par only). Reusable as a GPU-agnostic (Mac-safe, no compute) fluid reference.
3. **TD Depth Anything (69551, olegchomp, 3,555)** Depth Anything v1/v2 TensorRT inference inside TD (TopArray zero-copy tensors);
   `accelerate.bat` builds engines. MIT code, V2 weights Small Apache-2.0, Base/Large/Giant CC-BY-NC. Needs Python 3.11, CUDA 11.8, NVIDIA GPU, Windows:
   **not usable on this Mac**. Repo pushed 24 Oct 2026; tox opens donate/discord links via `webbrowser`. Author also runs vjschool.
4. **y=f(x) Volumetric lights (71960, timgerritsen, 2,733)** Post-process volumetric cone lights using the Light COMP shadow map, depth and
   world-normal buffers (Render TOP with 2 colour buffers + Render Select), optional 3D-texture smoke; "create vlight" button builds the extended
   Light COMP. 82-op tox, GLSL Multi compute + pixel, free, no licence, saved 2023.12230. Needs compute-capable GPU. Previs/LED-volume useful.
   Same author: "Let it snow" (68820, compute-shader snow).
5. **VIBE-Controller (74272, Infratonal, 2,684, Apr 2026)** Single-file HTML Canvas UI rendered in a Web Render TOP inside a Panel COMP; a Web Server
   DAT streams control values to CHOP channels. Ships a `CLAUDE.md` plus a `/sketch-to-interface` Claude Code skill so an agent can generate the HTML
   UI from text or a drawing. Basic free for Patreon members; Pro (bidirectional, 16 presets, auto-layout, 20 themes) is a paid tier. Files not fetched.
   **Most relevant find for this MCP** (agent-built TD control UIs). Author's other assets here: Instant Probe, AIMods_Sora2.
6. **Shadertoy2TD (67490, devart.space, 2,404)** Paste a Shadertoy URL, a Web Render TOP scrapes the shader (websocket JS), a Web Server DAT
   and Python build the GLSL TOP network (common + buffer passes; iTime, iMouse, iDate, texture/video/buffer/webcam channels; no cubemap, audio, keyboard).
   Free 36 KB tox, 324 ops, saved 2022.29850 Windows, no licence. Audit: web scraping, exec, onStart DAT; fine for sandboxed research only.
7. **Audioreactive Video Playhead - Definitive (72379, uisato, 2,182, Jul 2025)** Audio-driven video scrub VJ engine, new Veo (Gemini API)
   generator tox, MIDI/Ableton control, +125 timelapses. Patreon only, not fetched. Uisato also: LongExposureFX (74331), Kinect->Ableton (74013).
8. **OpenAI API (68939, leh0245, 2,170)** Chat Completion (GPT-4), DALL-E 3, TTS-1 via the `openai` pip package. Install `pip install openai`, point
   TD's Python 64-bit Module Path at site-packages (macOS paths given), supply your own key. Tested 2023.11340 + Python 3.11, saved on macOS;
   repo has no licence. Three tiny toxes (4-5 ops). Pattern for any pip-based API tool in TD.
9. **Terrain Tools (70216, Artcraft/CraftKontrol, 1,816)** Game-engine-style GLSL set: terrain (height + splat map), water, tree, grass, PBR, LOD
