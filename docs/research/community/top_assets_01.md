## Deep notes: 15 assets that matter most for an AI driving TD (listing rank in brackets)
1. **td-atlas** 75403 [67], griga, MIT, free. Python MCP + TD component: SQLite "atom index" of every op/param read from the user's own TD (13-16 s build), live bridge = Web Server DAT + callbacks DAT + status panel + Execute DAT, edits as one undoable block, `td_health` (dead branches, feedback loops that `cook(force)` does not advance, negative-float Level, bypassed gain ops, absTime non-determinism, licence-clamped res), `td_trace` (why is this TOP black), timeline walk/record/profile jobs (2x2 tiles past the 1280 cap), snapshot/variant save+diff, scope claims for several agents, call journal, offline .toe/.tox read/grep/diff/write. Measured on TD 2025.32460 macOS, Python 3.11+. Direct prior art: borrow `td_health`, `td_trace`, timeline-run, variants, scopes (clone `files/75403/repo`, 7.7 MB).
2. **Embody + Envoy** 70497 [107], dylanroscover, MIT. Release v6.2.76 tox (1.7 MB, built 2025.33230): automatic externalisation of COMPs/DATs plus **Envoy, an MCP server inside TD** (worker thread, port 9870, writes `.mcp.json`, ~70 tools: create/connect/set params, query_network, exec_python, capture_top, export/import network as .tdn, diff, claim_scope, batch_operations, run_tests...). Audit FLAGS: subprocess (git), urllib, pip/importlib env bootstrap. Biggest competitor/prior art; built on a newer TD than our 31550.
3. **TdHttpApi.tox + td-docs-mcp** 75078 [113], cacheflowe, MIT (docs MCP). HTTP bridge on 127.0.0.1:3031 (`/health`, network JSON, errors, DAT read, perf, `/network.mmd` mermaid, examples route, snapshot diff, run Python), embedded agent skills (`td-http-api`, `td-network-craft`, `td-common-mistakes`). Warns: no undo. td-docs-mcp = scraped docs.derivative.ca as markdown (45 MB repo, fuzzy search). Tox 235 KB, built 2025.33070.
4. **iTRAP / Banana API** 68832 [93], CorbinWhite, GPL-3.0. REST interface to a running TD: bearer tokens with per-user scopes, Swagger on :8000, API on :29980, "Map OP ID" exposure list, NAPs. Dependency-free tox (2022.32120); older but a clean security model reference.
5. **FunctionStore_tools** 68350 [94], function.store, MIT, 2,973 views. Toolbar helpers (default-param op placement, swap positions, promote pars, annotate), release v2.12.0 tox 3.7 MB. Audit: git via subprocess, osascript, requests (OLIB browser). Siblings: **TD Launcher Plus** 73935 (MIT; dmg/exe not fetched; utility tox audited), **TDMap** 74906 (MIDI mapping).
6. **RayTK 0.46** 72698 [14], tekt, CC BY 4.0, free. Raymarching/SDF framework (COMP ops emit GLSL, assembled in a GLSL TOP; threaded shader compile; image-based 2D SDF). 10.5 MB tox: 67,923 ops, 9,873 text DATs, built 2025.30770 on Windows; palette UI rewritten for TD 2025. Large; check against 31550 before loading.
7. **MaxMainio TD_ library** 74343/73606/74062/73301/74475 [4,16,17,25,53], MIT, free, built on **macOS** 2025.31760-32820. SDF (JFA, chamfer, smooth boolean), 18 edge detectors, Bayer/IGN/noise/error-diffusion dither, morphology, SVG import/export to cubic Bezier SOPs. Docs at maxmain.io.
