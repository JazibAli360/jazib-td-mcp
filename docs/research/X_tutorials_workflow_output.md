## 0. Summary

1. **Most real tutorial content for this area is a video behind a teaser page.** Derivative's community posts give title, author, date and a one-paragraph blurb; steps are only in the YouTube video. What can be extracted as hard facts is in Derivative's operator docs (Optimize, Performance Monitor, Probe, Syphon Spout Out, NDI Out, DMX Out, Movie File Out, Hap, Cache, Select, Window COMP, Perform Mode, camSchnappr, Kantan Mapper 2, Stoner), all read [V] and used for the recipes.
2. **New since the earlier files (2026 posts):** tekt's three pieces ("VJ Combining TouchDesigner and Resolume", Aug 2026; "Window COMP and Perform Mode", Jun 2026; "Build Your Own VJ Crossfader", Jan 2026), Elburz/Christian "Projection Mapping with TouchDesigner & MadMapper" (Aug 2026, Syphon/Spout into MadMapper), dcheesman's "Edge Feedback Concert Visuals" (Jul 2026), and the MUTEK 2026 Confluence talk on **okVJ** (free, open-source live toolkit by VJ BunBun and supermarket_sallad). okVJ's licence and repo URL could not be confirmed (Patreon-gated GitHub link, forum thread [V]).
3. **Performance workflow is well documented, GPU diagnosis is not.** The docs themselves say Performance Monitor "does not help much" for GPU work; Probe shows GPU time as diamonds, but its own page lists build 2021.10000 as latest and warns it costs up to a few ms [V]. The reliable GPU test is the resolution test (drop TOPs to 32x32 or 64x64; if fps does not change it is CPU) and the Info CHOP `gpu_memory_used` channel [V Optimize, Select TOP].
4. **Output facts that matter for Arena:** Syphon is **8-bit RGBA only** and same-machine only; the docs do not say how alpha is interpreted (premultiplied or not) [V Syphon Spout Out]. NDI Out has Include Alpha, 8/16-bit, a **Failover Source Name**, and Info CHOP channels `last_send_time` and `skipped_frames` [V NDI Out]. Touch Out/In carries Uncompressed / HAP Q / HAP Q Alpha over TCP and needs the same major release on both ends [V].
5. **Windows/NVIDIA-only (flag):** Video Stream Out TOP (NVENC, "requires an Nvidia GPU and Windows") [V]; StreamDiffusionTD **local** mode (NVIDIA >= 6 GB, CUDA 12.8, TensorRT; Mac only through "Daydream Cloud", internet required) [V dotsimulate docs]; Spout; Kinect/ZED/Notch TOP/NVIDIA Background and Upscaler (D). The old "Apple Silicon: Movie File In/Out not ported" note on Derivative's MacOS page is a 2022 text; `A_td_2025_howto.md` proves Hap Q and ProRes writing on this build, so treat that page as stale [V both].
6. **No Matthew Ragan first-hand material was retrievable.** He is credited only second-hand (Interactive & Immersive HQ's large-projects article points to his posts on external .tox and Git [S]; one Rutube re-upload credits Elburz and Ragan on "Easy Optimization Tricks" [S]). Nothing from his own site was read; none is cited as his words.
7. **Not found at all:** a free tutorial on a TD clip launcher with HAP preloading; any NotchLC-on-Apple-Silicon confirmation (Movie File In docs say NotchLC "always hardware decoded", no Mac statement [V]); any Mac-specific Syphon latency measurement; a Derivative Summit talk on a touring Resolume+TD rig. Open questions in section 4.
8. **MCP verdict.** Every network in the recipes can be built with `td_create`/`td_set_pars`/wiring/`td_exec`. What the MCP cannot do is the GUI-bound work: dragging corner pins in Kantan Mapper/Stoner, aligning 6 points in camSchnappr, learning MIDI, granting camera permission, and judging look quality (needs a screenshot and the user).

## 2. Recipes (12) for a touring concert rig feeding Resolume

All steps are op by op. Tags: [V] from Derivative docs read above; [U] my design. Nothing here was run in TD. Start each with `td_status`; end with `td_errors`. Create under one container (e.g. `/project1/show`) and use `td_layout`.

**R1. Find the bottleneck before changing anything** [V Optimize, Performance Monitor]
1. Add a Hog CHOP; compare fps with and without it (drop = CPU-bound). 2. Set the biggest TOP's resolution to 64x64: unchanged fps = CPU, faster = GPU. 3. Add a Perform CHOP (Frame Time, Cook) -> Trail CHOP; read through `td_get_pars`/`td_exec`. 4. Performance Monitor: Frame Trigger 100, Analyze, sort by Adjusted Length. 5. Read `gpu_memory_used` from an Info CHOP on each large TOP. 6. Delete the Hog CHOP. Output: a ranked list of nodes by ms and MB.

**R2. Resolution ladder with Select TOP** [V Select TOP]
1. Final look -> Null TOP `look_out`. 2. Select TOP `look_half` (`top`=look_out), Output Resolution = Half (Quarter/Eighth for previews). 3. A Switch TOP picks full / half; wire the monitor viewer to the cheap branch, the Syphon sender to the chosen one. 4. Use Preferences > TOPs global res multiplier for editing. 5. Note: Select shares the instance and costs no extra texture. Matches the fallback in E (3744x1440).

**R3. Syphon output to Arena** [V Syphon Spout Out; E for the Arena side]
1. Null TOP `to_arena` after the final comp (+ Fit/Resolution TOP to the atlas size). 2. Syphon Spout Out TOP: `sendername`="TD_PF26" (stable name), `active`=1, `format` = 8-bit (Syphon cannot carry more). 3. Info CHOP on the sender to confirm cook time. 4. In Arena add the source, set the layer to Add/Alpha per R of `R_show_safe_interactive.md`. 5. Premultiplied vs straight alpha is not documented: test with Arena's blend, not a composite [U].

**R4. NDI fallback for two machines** [V NDI Out]
1. NDI Out TOP: Source Name "TD_PF26", Include Alpha on only if needed, 8-bit unless HDR; Failover Source Name = backup machine "NAME (TD_PF26)". 2. Low-performance behaviour: skip frames, so the cook stays smooth. 3. Info CHOP (`last_send_time`, `skipped_frames`) -> Logger (R11). 4. Alternative TD<->TD: Touch Out (Port, HAP Q, `fps`=30) -> Touch In; same major release.

**R5. Perform window on the wall output** [V Perform Mode, Window COMP]
1. Window COMP `perform`: `winop`= the output container; Borders off; Justify = Specify Display with `display` index; Opening Size = Fill Location; Cursor Visible = Never; VSync Enabled. 2. Set as Perform Window (Window Placement dialog); optionally Start in Perform Mode. 3. macOS: turn off "Displays have separate Spaces" in Mission Control before using Bounds of All Displays. 4. Enter with `td_exec("ui.performMode=True")` only when the user approves; test every cue in perform mode (R of `R_show_safe_interactive.md`).

**R6. Clip deck of HAP loops (movie bin)** [V Movie File In, Hap; layout U]
1. Re-encode media: `ffmpeg -i in.mov -c:v hap -format hap_q -chunks 12 out.mov` (no alpha for Hap Q; Hap Alpha if needed). 2. One Movie File In TOP per clip, `Pre-Read Frames` set, Play Mode = Sequential (loop) and Active only on the selected clip. 3. Switch TOP (`index`) -> Cross TOP A/B for the transition, or sceneChanger from `H_control_panel.md`. 4. Check Info CHOP `fully_pre_read`; use High Performance Read for 4K+ Hap Q. 5. Disk speed is the limit, not GPU: record an SSD benchmark before trusting N simultaneous clips.

**R7. Cheap trails with the Cache TOP** [V Cache TOP]
1. Source -> Cache TOP (`cachesize` 8-16, `active`=1). 2. Several Select TOPs or a Time Machine style tap: Output Index 0, -2, -4, -6 into a Composite/Add chain with decaying Level TOP. 3. Keep size small (GPU memory); `reset` pulse to free. 4. Use instead of a feedback loop when you need crisp, controllable trails.

**R8. Edge-feedback concert look with keyboard hits** [V post teaser, ops named there; wiring U]
1. Source -> Edge TOP -> Composite (Over) with Feedback TOP target -> Lookup TOP (gradient from the PRISM palette) -> Displace TOP (self displace) -> Bloom -> Null. 2. Keyboard In CHOP / Panel -> Pulse -> a Level TOP flash (cap with the 3 flashes/s limiter; see K). 3. Expose Edge size, displace weight, feedback decay as custom pars.

**R9. LED fixture mapping out of a TOP over Art-Net** [V DMX Out; forum pipeline]
1. Fixture list Table DAT (x, y per pixel). 2. Resolution TOP / Crop to the grid size; Interpolate = nearest. 3. TOP to CHOP -> Shuffle CHOP so channels read r,g,b per pixel. 4. Split into 170 pixels (510 channels) per universe; DMX Out CHOP: Interface Art-Net, Net/Subnet/Universe per chunk (Packet Per Channel with a Routing Table DAT if many), `Rate` 44, `Local Address` = the NIC on the lighting network. 5. Keep `Active` off until the user approves any network send. This is not needed if Arena does the pixel map.

**R10. Single-surface warp with Stoner (preview projector, rehearsal)** [V Stoner]
1. Look -> Stoner (Palette > Mapping); set `Project` to a Base COMP to hold data. 2. Open Stoner window: keystone (k), grid (g), nudge with arrows. 3. Read the displacement-map output into a Remap TOP; remove Stoner, keep the data. 4. Output on a Window COMP at the projector monitor. Kantan Mapper 2 is the alternative for several quads/masks; both need the mouse (MCP can build, user aligns).

**R11. Soak telemetry log for a 6 h show** [V Optimize; wiring U]
1. Perform CHOP + Info CHOPs (`gpu_memory_used`, sender `skipped_frames`/`last_send_time`) + Time CHOP -> Merge. 2. Record CHOP (or Script CHOP appending to a Table DAT) at 1 Hz -> write CSV via DAT Execute every 60 s. 3. Add a threshold Logic CHOP -> OSC Out to Arena's layer opacity (see `R_show_safe_interactive.md`). 4. Cmd-P Probe stays hidden during the show (it costs ms).

**R12. Frame-exact loop render, then ProRes/Hap master** [V Movie File Out, Recording Movies; A for the probe]
1. Loop length N frames at 30 fps on the timeline range. 2. Movie File Out TOP: `videocodec` prores (or hap + `videocodectype`=Hap Q), set file name with `unique` suffix; Realtime flag OFF. 3. Prefer File > Export Movie over timeline range for repeatability; reset Speed/Count CHOPs before each take. 4. Pulse `record`, step N frames, stop; verify file frame count with ffprobe (A saw 69 vs 71). 5. For alpha use Hap Alpha/ProRes 4444 and respect the premultiplied rule (memory `overlay-alpha-premultiplied`).

Camera/IMAG chains are not repeated here (see `D_camera_mediapipe.md`, `J_interactive_camera_effects.md`). Only the new doc facts: Blob Track needs 2 inputs (live + saved background) for the fast background-subtraction mode; Video Device In `Driver`=AVFoundation, watch Info CHOP `frames_dropped` [V]; the camera permission prompt is a user action.
