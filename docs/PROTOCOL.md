# PROTOCOL: bridge and TouchDesigner (v1)

```
Claude --stdio--> src/server.js (MCP) --HTTP POST /ctl + x-jtd-token--> src/bridge.js (127.0.0.1:9335, detached)
                                                                           ^ WebSocket (TD dials out) + hello token
                                                   TD: /jazib_mcp COMP (WebSocket DAT client + callbacks DAT)
```

TD opens no port. Only the bridge listens, and only on 127.0.0.1.

## Token
- File: `~/Library/Application Support/JazibTDMCP/token` (override `JTD_STATE_DIR`): 48 lowercase hex chars, mode 600.
  Whichever side runs first (bridge or TD) creates it. TD reads it each time it connects, and **it is never stored in
  the `.tox`**.
- HTTP: every request except a bad-origin one needs header `x-jtd-token`.
- WebSocket: the first message from TD must be the hello (below), sent within 5 s. Otherwise the bridge closes.

## Origin rule (keeps web pages out)
A request or upgrade whose `Origin` header is present and starts with `http:`, `https:` or `file:` is refused
(HTTP 403 / socket destroyed). TD's WebSocket DAT may send no Origin, or one of its own; any other value is allowed
and logged. The bridge accepts an upgrade on any path (TD's WebSocket DAT path handling is unverified); auth is the hello token.

## WebSocket messages (JSON text frames)
TD -> bridge, first message:
```json
{"type":"hello","token":"<48 hex>","td":{"build":"2025.31550","version":"...","osName":"...","project":"x.toe","folder":"/abs","pid":123,"protocol":1}}
```
The bridge keeps one TD connection; a newer hello replaces the old one (the old socket is closed).

bridge -> TD keepalive every 20 s: `{"type":"ping"}`, and TD answers `{"type":"pong"}`.

bridge -> TD request: `{"id":7,"cmd":"list","args":{...}}`
TD -> bridge reply:  `{"id":7,"ok":true,"result":{...}}` or
`{"id":7,"ok":false,"error":"msg","traceback":"..."}`

TD -> bridge, unsolicited: `{"type":"log","level":"info|warn|error","msg":"..."}`, which goes to bridge.log.

## HTTP (MCP server -> bridge)
- `GET /health` -> `{"ok":true,"td":true|false,"tdInfo":{...hello.td, since},"pid":n}`
- `POST /ctl` body `{"cmd","args","timeoutMs"}` (default 60000) -> `{"ok":true,"result"}` | `{"ok":false,"error","traceback"?}`.
  503 + `ok:false` when TD isn't connected ("TouchDesigner not connected: open TD and load /jazib_mcp (see README)").
